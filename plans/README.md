## Findings considered and rejected

- Fixed default profile/context, report-only cleanup, configurable local executables and ad-hoc signing: documented choices.
- Automatic rollback after failed VM start: no safe universal recovery guarantee.
- Broad grouping/index performance rewrite: no measured benefit for current inventory.
- Swift 6 language-mode migration: no demonstrated compatibility defect; no third-party Swift package migration required.
- Generic pre-commit/caching changes: verification and dual-architecture CI already work.
- AI chat, Kubernetes, automatic volume prune, filesystem editing and copying OrbStack runtime networking: outside the immediate product task.
